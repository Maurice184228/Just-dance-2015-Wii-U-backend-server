# Just dance 2015 Wii U backend server

# About

This repository addresses the just dance 2015 game on Wii U only, providing an alternative of the original discontinued servers. My recreation of Ubisoft's backend server of just dance 2015 Wii U has been developed from scratch specifically the ubiservices, rendez vous and Hermes side. Ensuring comprehensive transparency and fostering user confidence. The project aims to deliver a unique user experience especially for those who never played on original servers.

# Current stage of development

Currently this just dance 2015 backend server of Ubisoft is still under early stages of development.

# Current progress status

Since it's still under early stages of development it's about 10% done.
